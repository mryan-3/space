# AR Room Preview

## 1. Overview

A lightweight web app that allows users to preview 3D objects in their real environment using their phone camera before physically placing or purchasing them.

## 2. Problem

People often struggle to understand how a piece of furniture or object will look, fit, and feel within their actual space when viewing it only through images or traditional 3D previews.

## 3. Goal

Allow a user to select a 3D object, place it in their real environment, and interact with it as though it were physically there.

## 4. Core User Flow

1. User opens the app.
2. User browses available objects.
3. User selects an object to preview.
4. User views and explores the object.
5. User chooses **“View in My Space.”**
6. User grants camera access.
7. User points their phone at the floor.
8. User taps a location to place the object.
9. The object appears in the real environment.
10. User moves, rotates, or resizes the object.
11. User can remove it and try another location or object.

## 5. MVP Features

### Object Library

* Display a small collection of 3D objects.
* Object name and basic information.
* Preview each object before entering AR.

### 3D Preview

* Rotate the object.
* Zoom in/out.
* Inspect the object from different angles.

### AR Placement

* Open the phone camera.
* Identify a suitable surface.
* Place the selected object in the environment.
* Keep the object anchored while the user moves around.

### Object Controls

* Move.
* Rotate.
* Resize.
* Remove/reposition.

## 6. Example Use Case

A user wants to replace their current study-room desk.

Instead of imagining how a new desk will fit from a product photo, they open the app, select the desk, and place it beside their existing desk through their phone camera.

They can walk around it, adjust its position and size, and determine whether the desk works in the available space.

## 7. Success Criteria

The MVP should allow a user to go from:

**Select object → View in space → Place → Adjust → Evaluate**

with as little friction as possible.

## 8. Future Possibilities

* User-uploaded 3D models.
* Furniture catalogues.
* Accurate real-world measurements.
* Multiple objects in one scene.
* Save and share room layouts.
* Room scanning.
* Architectural/BIM model visualization.
